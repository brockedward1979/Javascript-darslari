Animatsiyani boshlash uchun ▶ Keyingi qadam tugmasini bosing.
Har bir qadam Event Loop ning bir bosqichini ko'rsatadi.
Har bir jarayon — batafsil tushuntirish
1
Call Stack — Sinxron kod
Sinxron
Call Stack (chaqiruvlar to'plami) — JavaScript ning asosiy ijro mexanizmi. Kod yuqoridan pastga, ketma-ket bajariladi. Hech narsani kutmaydi, bloklamaydi.

Qanday ishlaydi: Har bir funksiya chaqirilganda stack ga "push" qilinadi. Funksiya tugagach "pop" qilinadi. Stack bo'sh bo'lganda Event Loop ishga tushadi.

Misol: console.log('1: Start') → darhol chop etiladi.
⚡ Qoida: Sinxron kod har doim birinchi bajariladi. Hech bir asinxron jarayon unga to'sqinlik qila olmaydi.
2
Web API — Brauzer xizmatlari
Web API
Web API — bu JavaScript tili emas, brauzer (yoki Node.js) tomonidan taqdim etilgan xizmatlar. setTimeout, fetch, DOM events shular jumlasidan.

Qanday ishlaydi: setTimeout(cb, 0) chaqirilganda callback JS dan "olib chiqilib" Web API ga beriladi. Brauzer timerni alohida hisoblaydi — JS to'xtamaydi! Timer tugagach callback Macrotask Queue ga o'tadi.

Muhim: Hatto setTimeout(fn, 0) ham darhol bajarilmaydi — Macrotask Queue orqali kutadi.
🌐 Web API parallel ishlaydi — JS single-threaded, ammo brauzer multi-threaded.
3
Microtask Queue — Yuqori ustuvorlik
Microtask
Microtask Queue — eng yuqori ustuvorlikdagi asinxron navbat. Promise.then(), Promise.catch(), queueMicrotask(), async/await shular orqali to'ldiriladi.

Qanday ishlaydi: Promise.resolve().then(cb) → callback darhol (sinxron qismda) Microtask Queue ga tushadi. Call Stack bo'shashi bilan barcha microtasklar birinchi navbatda bajariladi.

Tartib: Call Stack bo'shadi → barcha microtasklar → keyin bitta macrotask → yana microtasklar (agar paydo bo'lsa).
⚡ Muhim: Agar microtask ichida yangi microtask hosil qilinsa, u ham shu "tur"da bajariladi — makrotaskdan oldin!
4
Macrotask Queue — Standart navbat
Macrotask
Macrotask Queue (Task Queue yoki Callback Queue ham deyiladi) — setTimeout, setInterval, I/O, click kabi hodisalar shu yerga tushadi.

Qanday ishlaydi: Timer tugagach yoki hodisa bo'lgach, callback bu navbatga qo'shiladi. Event Loop har safar Microtask Queue bo'shagandan keyingina bu yerdan bitta task oladi.

Farqi: Microtask dan farqli ravishda, har bir "Event Loop turida" faqat bitta macrotask bajariladi, keyin yana microtasklar tekshiriladi.
⏰ setTimeout(fn, 0) aslida "imkon topilsa bajar" degani — hech qachon "darhol" emas.
5
Event Loop — Bosh koordinator
Event Loop
Event Loop — JavaScript ning "yurak urishi". U doim ishlaydi va quyidagi tartibni takrorlaydi:

1. Call Stack bo'shmi? → Yo'q: kutadi. Ha: davom etadi.
2. Microtask Queue bo'shmi? → Yo'q: barcha microtasklar bajariladi.
3. Macrotask Queue bo'shmi? → Yo'q: bitta macrotask bajariladi.
4. Render kerakmi? → Ha: sahifa yangilanadi.
5. 1-qadam dan takrorlanadi.
🔄 Bu sikl to'xtamaydi — brauzer yopilguncha yoki skript tugaguncha davom etadi. Shuning uchun JS "bloklanmaydi".
6
Yakuniy chiqish tartibi — Nima uchun?
Natija
Ushbu kodning chiqishi:

1: Start → 2: Middle → 3: End (sinxron)
→ 4: micro1 → 5: micro2 → 6: micro3 (microtask)
→ 7: timeout1 → 8: timeout2 → 9: timeout3 (macrotask)

Nima uchun shunday? Sinxron kod to'liq tugaydi → Microtask Queue butunlay bo'shatiladi → Keyin Macrotask Queue dan bittadan olinadi.
💡 Asosiy qoida: Sinxron > Microtask > Macrotask. Buni yodda saqlasang, Event Loop sir bo'lmaydi!
